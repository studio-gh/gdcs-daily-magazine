The main event: ten current AI and design-tool stories with direct creative-workflow relevance.

Figma Release NotesDesign systems

Figma turns design-system drift into a one-click QA moment.

Figma’s new Check designs feature compares work against the team’s design system, flags hard-coded color, text, radius, and spacing values, and suggests the right tokenized fix. It also checks contrast, library mismatch, and detached components, which makes this more than a tidy-up feature.

For Creative Studio, the important shift is where quality control happens. Instead of waiting for a late review to catch drift, designers can run a calmer pass while the file is still alive, especially before handoff or campaign-system reuse.

The caveat: Figma says Check designs is available on Organization and Enterprise plans, so this is a workflow signal to investigate rather than an assumed team default.

Figma Release NotesUpdate

Update: Make adds a planning layer before the AI starts building.

Last week’s issue covered Figma Make moving closer to implementation. The material update is Plan mode: an opt-in step where Make reviews the project, asks clarifying questions, drafts a plan, and waits for approval before generation starts.

That sounds procedural, but it is a real creative-control change. For multi-section layouts, design imports, and detailed specs, the better workflow is not “generate faster”; it is “align the brief before the tool commits.”

Figma also notes that Plan mode uses more AI credits than a standard build, with an estimate shown before committing. Budget visibility is becoming part of art direction.

Figma Release NotesAI operations

Figma’s Professional plan now has a pressure valve for AI-credit spikes.

Admins on Figma Professional can now buy additional AI credits on a pay-as-you-go basis. The update is not as visually exciting as a new generator, but it changes how teams can pilot AI-heavy workflows without immediately changing plan structure.

The editorial takeaway is simple: creative automation is becoming a managed resource. If a studio starts using AI for image-heavy slides, Make builds, or campaign-scale variants, credit planning needs to sit next to staffing, timeline, and review planning.

This is adjacent to last week’s AI-credit coverage, but the new development is availability for Professional-plan admins rather than only higher-tier governance.

Figma Release NotesComponents

Slot settings make component flexibility less fragile.

Figma’s new slot settings let teams define minimum and maximum layers, limit what instances can go into a slot, show empty slots by default, and set fill behavior. Slots are now generally available.

For a graphic design team, this matters because “flexible” components often become inconsistent components. Better slot guardrails can protect campaign templates, presentation modules, and repeated UI-like marketing systems without making every layout feel locked down.

The bigger pattern is worth naming: design tools are moving from component storage to component behavior. The system increasingly teaches the designer how it wants to be used.

Canva NewsroomVisual trends

Canva’s 2026 trends argue for AI with fingerprints left in.

Canva’s 2026 Design Trends report names the year’s creative theme as “Imperfect by Design,” drawing on platform behavior, creator research, and advisory-board input. The report’s core tension is useful: AI is becoming a normal creative partner, while creators are pushing back against overly polished, algorithmic sameness.

For PMI work, the most useful trends are not decorative labels. “Explorecore,” “Texture Check,” “Zinegeist,” and “Opt-Out Era” point to layouts that slow people down, bring tactile cues forward, and make generated work feel more human.

The watch-out is restraint. Trend language should become a critique vocabulary, not a mandate to chase every aesthetic at once.

OpenAI Help CenterImage editing

ChatGPT Images is now framed as an editable image workspace, not just a prompt box.

OpenAI’s Images in ChatGPT guidance states that ChatGPT Images 2.0 is available on all tiers, with Images with thinking on Plus, Pro, and Business and coming to Enterprise and Edu. The editor supports selection-based edits, direct conversational edits, aspect-ratio changes, undo/redo, and saving.

The creative implication is practical: the image tool is becoming a light production space for exploration, transparent-background needs, text-in-image attempts, and quick iterative edits. It still needs designer judgment because selection highlights are not guaranteed to be precise.

For the team, the best use case is not final brand artwork. It is rapid option-making before a designer moves the strongest direction into a controlled design environment.

Microsoft SupportBrand governance

Copilot Brand kits turn brand management into a generation constraint.

Microsoft’s May 2026 guidance describes official Brand kits in the Microsoft 365 Copilot app, managed by designated brand managers. Kits can include logos, color palettes, typography, layout patterns, icons, data-visualization styles, photography rules, brand voice, and do/don’ts.

The most relevant detail is Brand Reviewer: Microsoft says it can identify issues and suggest one-click fixes for incorrect colors or fonts, misplaced logos, off-brand imagery, layout, spacing, and alignment issues.

This is the enterprise version of a familiar design-team tension: people need to make materials quickly, but the system has to protect the brand while they do it.

Adobe HelpCopilot integration

Adobe Express inside Copilot is a template workflow hiding in chat.

Adobe’s Express agent for Microsoft 365 Copilot lets users create, customize, and export flyers, posters, social graphics, and similar assets without leaving Microsoft’s environment. The agent can search templates, fill text, replace images, change backgrounds, and add animation.

This is not a replacement for Creative Studio craft. It is a new intake surface. Internal partners may increasingly arrive with rough Copilot-generated Express drafts instead of a blank request, which makes template governance and editability more important.

The healthiest stance is to define which Express outputs are self-serve, which need design review, and which should graduate into a more controlled Adobe or Figma production file.

Adobe HelpCreative ops

Adobe’s generative-credit map makes model choice part of production planning.

Adobe updated its Creative Cloud Generative AI features page on June 1, clarifying standard versus premium features across applications. Standard generations such as Photoshop Generative Fill usually consume one credit, while premium features such as video generation and partner models can use more depending on model selection, output, and file size.

The useful lesson is operational: when a creative workflow uses Google, OpenAI, ElevenLabs, or other partner models inside Adobe, that choice affects cost and quota as much as aesthetics.

For larger campaign systems, the brief should start capturing which generative steps are exploratory, which are production-facing, and which require premium-model budget.

NotebookLM HelpPresentations

NotebookLM’s slide deck workflow is moving from generated artifact to revisable communication tool.

Google’s NotebookLM help now details slide-deck generation with format, language, length, and style prompts, plus a revision flow where users can edit text, change layouts, or update visuals across multiple pending slide changes. Generated decks can be downloaded as PDF or PowerPoint.

This is directly relevant to presentation work because source-grounded decks are becoming a first-draft behavior across the tool landscape. NotebookLM is strongest when the task is synthesis and explanation, not brand-perfect layout.

The craft opportunity is to treat NotebookLM as a narrative extractor: let it find structure, then rebuild the hierarchy, typography, and brand expression with human intent.

Inspiration

Small craft prompts to carry into layouts, presentations, motion studies, and review rituals this week.

Layout

Design the check before the asset leaves the file.

Borrow from Figma Check designs: every reusable template should have a preflight moment for contrast, tokens, logo placement, imagery style, and layout drift.

Typography

Let imperfection be intentional, not accidental.

Canva’s trend signal is useful only when the roughness has a point. Use handmade texture, zine cuts, or lo-fi type to create warmth, not to cover unclear hierarchy.

Presentations

Separate narrative extraction from deck design.

NotebookLM and Copilot can help find a structure. The design team’s value is deciding what deserves emphasis, what should be removed, and how the story should feel in PMI’s voice.

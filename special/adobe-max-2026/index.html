Adobe MAX 2026 / Miami Beach / Special report

The native file fights back.

Agents arrive inside Creative Cloud, Firefly becomes a full creative studio, and Adobe makes editability its line in the sand.

Miami Beach, Florida
Edited for visual teams

The headline is not “more AI.” It is a new production argument: delegate the busy work, keep the working file.

Adobe MAX returned to Miami Beach with a release slate that reaches from one-click image repair to always-on agents. The most consequential move is architectural. Adobe is putting its Creative Agent across flagship apps and previewing local MCP integrations that let third-party agents act on Photoshop, Illustrator, Premiere and After Effects files.

The guardrail is also the pitch: the output stays inside native, editable project structures. For studios nervous about flattened AI artifacts, that matters more than another prompt box. It reframes the agent as production support rather than a replacement surface.

Editor’s take: Adobe is trying to own the handoff between generative possibility and production reality.

01 / The big shift

From assistant to operator.

Creative Agent

Multi-step work, inside the app

AI Assistants in Premiere, Illustrator, InDesign, After Effects and Frame.io can interpret a goal and orchestrate multiple steps. In Premiere, Adobe says the agent can apply effects across a sequence, track masked subjects and adjust color and exposure across the cut.

Local MCP / Preview

Bring your own agent

Photoshop, Illustrator, Premiere and After Effects are being opened to preferred third-party agents through local MCP integrations. The project stays on the user’s computer and native structures remain editable. Private beta is planned for early 2027.

Plan Mode

Approval before action

Firefly’s Creative Agent adds customization, a reviewable Plan Mode and a Model Selector. That makes process visibility and model choice part of the interface rather than a hidden system decision.

Always-on / Preview

Work continues in the background

Adobe previewed recurring agents for jobs such as organizing incoming footage, removing duplicates and flagging quality problems. A central dashboard keeps approvals and intervention points visible. Beta is expected in early 2027.

02 / Creative Cloud

The updates worth opening the app for.

Ps

Photoshop

Relight adds adjustable light sources; Generative Restyle converts a prompted variation into a layer with an intensity slider. Related-elements removal catches shadows and reflections, while Quick Compare adds an on-canvas before/after view. Beta work includes Mockups, Camera Angles, Generative Recompose, Convert to Text Layers, Timelapse and ambient-effect removal.

Pr

Premiere

Color Mode is now generally available. Generative Media puts video, music, sound effects and soundscapes in the timeline with Adobe and partner models. Enhance Audio, Separate Crosstalk and Separate Sound Source attack difficult recordings; Generative Remove is in beta for tracked object removal.

Lr

Lightroom

Glow adds cinematic diffusion and halation. Blemish Removal moves from mobile into the broader Lightroom workflow with finer controls. Camera Tethering expands across desktop and iPad. Open Eyes, in public beta, repairs a blink using a reference image of the same person.

Ai

Illustrator

Refreshed libraries add brushes, graphic styles, patterns and gradients. New on-canvas Blend controls keep a persistent control panel and live preview close to the artwork, a quieter update with everyday value.

Id

InDesign

Co-editing enters public beta for simultaneous layout work. Flex Layout dynamically resizes text frames, while Check Document and Rewrite surface editorial and accessibility issues before the file leaves the layout.

Tz

Topaz models

Following Adobe’s acquisition of Topaz Labs, Wonder 4 combines upscaling, denoising, deblurring and sharpening. Image HDR converts standard images to HDR with greater brightness and detail. Both are positioned as optional enhancement models.

03 / Firefly

Adobe turns the model shelf into a studio floor.

Firefly Video

A narrative-to-timeline workflow for scenes, clips, captions, generated transitions and missing b-roll. It puts planning and finishing closer together.

Firefly Design / beta

Illustration, raster editing, animation, 3D and print share one canvas. Adobe pitches a single file from brand identity or package concept through client review.

Firefly Image

Edit Object, Edit Text, Relight and Retouch aim for localized change without disturbing the rest of the image.

Firefly Graph / beta

A node-based environment for repeatable workflows across Adobe tools and third-party models. An assistant can help build and optimize the graph.

Firefly Builder / private beta

Natural-language design-to-code for on-brand websites, presentations and apps, with direct canvas editing and a design system keeping components coherent.

Model choice

Firefly expands its shelf across Adobe, Topaz Labs, Google, OpenAI, Kling, ByteDance, ElevenLabs and others. The strategic shift is from one house model to a controlled model marketplace.

05 / Wider signals

The platform story extends beyond Adobe’s own canvas.

Google

Models in, tools out

Google’s frontier models move deeper into Adobe products, while Adobe tools expand into Workspace, Gemini and AI Mode. Adobe and DeepMind will also explore Photoshop editing capabilities.

Microsoft

Arm-native pro apps

Optimized Photoshop, Premiere, After Effects and Substance 3D Painter are coming to high-performance Arm Windows PCs. Express capabilities move into Microsoft Photos.

Disney

Custom models meet IP

A multi-year alliance makes Adobe an official AI innovation partner. Disney Imagineering is already using a custom sketch-to-image model in concept development.

GenStudio

Brand context as infrastructure

CX Enterprise Coworker, Brand Intelligence, intelligent adaptation and governed Firefly Graph workflows aim to make scale less destructive to brand consistency.

06 / Studio playbook

Four tests for Monday morning.

Run a native-file audit

List every AI-assisted handoff that produces a flattened asset. Identify where a native, editable output would remove rework or approval risk.

Build one repeatable graph

Use a low-risk adaptation task, such as product crops or campaign sizes, to test Firefly Graph without letting automation choose the creative direction.

Benchmark the quiet upgrades

Time a real job with Premiere Color Mode, InDesign Flex Layout or Photoshop Quick Compare. The useful release may be the one with the least theatrical demo.

Write the approval map first

Before testing agents, define which steps can run unattended, which require review and which must remain entirely manual. Plan Mode is only useful if the team has a plan.
